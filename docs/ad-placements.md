# 広告枠の準備と有効化条件

現状は審査待ち。すべての枠は hidden の空要素で、通信・Cookie・余白は発生しない。トップ・カレンダー・運営案内には追加しない。

- listing-inline: 検索・エリア・テーマ一覧の4件目の後。5件以上ある場合だけ1枠。
- facility-after-info: 無料条件、アクセス、営業時間、公式リンクの後。静的詳細では関連ページの前に1枠。

有効化時は審査承認を実測確認し、AdSenseで手動の広告ユニットを作成して実在するIDを使う。自動広告はオフにして、意図しない追加枠を防ぐ。広告・プライバシー案内と対象地域の同意処理を更新してから配信コードを導入する。プレビューと旧GitHub Pagesには配信しない。空広告は畳み、広告が表示される場合だけ「広告」と明示する。

初回は一覧1枠・詳細1枠。表示速度、ページ閲覧数、回遊、推定収益を比較する。広告クリックを促す案内はしない。
