# 施設・エリア拡充
目的：SNSのエリア別・テーマ別まとめから、サイトの候補比較と施設詳細への訪問を増やす。

1. 東京・神奈川・大阪の確認済み施設を増やし、28日間の掲載間隔でも週末のまとめを用意できる候補数を確保する。
2. 隣接エリアの千葉・埼玉を調査し、無料範囲・対象者・開館時間・祝日振替休館・交通情報が揃った施設から掲載する。
3. 雨の日・親子向けはカテゴリから推定せず、屋内展示や対象年齢など公式の根拠を記録する。

調査候補：千葉市立加曽利貝塚博物館。千葉市公式で博物館展示室・野外施設の無料を確認。

https://www.city.chiba.jp/kasori/infomation/guide.html
まだ掲載データへ追加していない。休館日・アクセス・臨時のお知らせを確認後に追加する。
