# エリア別SNS運用（費用ゼロ）

表示名：無料デー検索。希望ユーザー名：free_day_search（空き状況による）。

## 現在の動作

月・水・金17:00 JSTにX、火・木17:00 JSTにInstagram画像カルーセルを予定する。
各投稿は一つの都道府県・市区町村の施設を紹介。確認済みで、大人の無料条件と開館日を満たす候補だけを選ぶ。エリアを順番に回し、候補がないエリアは飛ばす。施設詳細リンクには媒体別UTMを付ける。
音声・動画・有料APIは使わない。画像は文字と図形だけで自作し、第三者写真を自動収集しない。

毎週日曜08:35 JSTにGitHub Actionsが次の月曜から2週間分の投稿文・画像・計測表を自動作成する。ジョブが遅れる場合がある。Actionsのarea-sns-kit成果物をダウンロードしてindex.htmlを開く。
これは素材生成の自動化であり、SNSアカウントへの予約登録は別工程。予約登録後の公開はSNSの予約機能が実行する。アカウント作成・予約完了までは実際に投稿されない。

## 最初の接続

1. ユーザー本人がX・Instagramの登録、パスワード設定、本人確認、規約への同意を完了する。パスワードや確認コードをリポジトリ・チャットへ保存しない。
2. プロフィールにサイトURLを設定。Instagramは無料のプロアカウントへ切り替え、アプリ内予約またはMeta Business Suiteを使用する。Business Suiteの接続はユーザーが権限内容を確認する。
3. 各投稿の施設公式URLで無料条件・対象日・臨時休館を再確認し、候補画像をレビューする。計測リンクはキット内のリンク・計測表から使用する。Instagramの公開本文には長い操作用URLを含めない。
4. Xにx.png、Instagramにcarousel-01〜04.pngをアップロードし、予定日時で予約する。予約一覧でアカウント・日時・画像を確認する。
5. 計測表へ予約済み・公開URLを記録する。毎週生成する2週間分は重なるため、既に予約済みの投稿を二重登録しない。新しい週の枠だけ追加する。

予約状態は外部SNSから自動取得しない。キット内の重複回避は候補間およびsocial/history.jsonの実投稿履歴による。別キットの予約済み投稿は計測表・SNS予約一覧で確認する。

## 手元で作成

```sh
npm run social:pack -- --start 2026-10-12 --weeks 2 --areas 東京都,大阪府
npm run social:images
```

画像処理にはPillow、日本語フォントが必要。SOCIAL_FONTでフォントを指定可能。文字が枠に収まらない場合は失敗させ、条件を黙って省略しない。

## 停止・費用

Xの旧API投稿ジョブはSOCIAL_POSTING_ENABLED=falseのまま。今回のワークフローは認証情報を参照せずAPIを呼ばない。
素材生成を停止する場合はWeekly area SNS imagesワークフローを無効化する。予約済み投稿の停止はSNS側で行う。
無料GitHub Actions枠を利用し、有料の課金設定は追加しない。X APIの完全自動投稿は現時点で有料のため保留。

## エリア別まとめ（2026-10-11）
週次ワークフローは `--roundup` を指定し、同一都道府県の確認済み候補を2〜3施設まとめます。施設ごとに候補日・無料の範囲・対象者・休館情報を保持します。候補日が異なる場合もあるため、同日に全施設が無料という表現は使いません。Instagramは表紙・各施設・案内の4〜5枚です。
素材生成は毎週日曜8:35（日本時間）。Instagramへの予約登録・公開はこのワークフローに含みません。アプリの予約投稿またはMetaの公式予約機能で、内容確認後に登録してください。有料APIは使いません。
