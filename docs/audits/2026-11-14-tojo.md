# 戸定が丘歴史公園 東屋庭園（確認2026-11-14）

公式の施設案内、戸定の日案内、開館カレンダーを確認。

東屋庭園の無料見学のみを登録。書院造庭園は戸定の日も入館料が必要であり、無料日として登録しない。9〜17時、月曜祝日は開園し翌平日休園、12/28〜1/4休園。松戸駅東口約10分。歴史館の展示替えは公園休園に適用しない。バス駐車は予約必要、ペット不可（補助犬例外）。

重複は現在のデータと過去追加台帳で確認。8日付境界で通常週末、月曜、祝日月曜、その翌日、年末年始、歴史館展示替え中の公園開園を確認。公開は未実施。
