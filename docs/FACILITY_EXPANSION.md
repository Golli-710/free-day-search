# 掲載範囲の拡張

従来の目的は、SNSのエリア別・テーマ別まとめから施設比較と詳細閲覧を増やすことです。既存エリアの候補を厚くして28日間の掲載間隔を保ち、雨の日向け・親子向け等はカテゴリだけから推定しない方針を維持します。無料範囲、対象者、休館、アクセスの公式根拠を揃えます。

以前の調査候補だった加曽利貝塚博物館は掲載済みです。埼玉の宇宙劇場は大人のプラネタリウムが有料のため、全館無料として追加しません。無料展示の範囲を別途確認します：https://www.city.saitama.lg.jp/008/017/003/p034849.html 。

2026-10-21の第1弾は61→64施設、4→5都府県、7→8カテゴリ。埼玉県と工場見学を追加。本番反映前の実装値です。

## 公式確認先

- グリコピア・イースト：https://www.glico.com/jp/enjoy/experience/glicopia/east/ 。通常見学無料、完全予約制、2名以上。有料体験は別料金。土日のポッキー製造ラインは映像で紹介されます。
- 赤城乳業：https://www.akagi.com/factory/ 、https://akagi-tour.com/users/index 。無料、全日程抽選。応募は希望月2か月前の1〜20日。住所の補助資料：https://www.pref.saitama.lg.jp/documents/25611/r7ichiran.pdf 。
- キッコーマン：https://www.kikkoman.com/jp/shokuiku/factory/noda/ 。無料、前営業日まで予約、当日予約不可。通常土日祝休館。中学生以下は保護者同伴。

## 料金と日程を分ける

`reservation_required: true` は無料料金と参加できる日を区別します。`always_free` は参加費のルールであり、毎日参加できるという意味ではありません。空き枠は取得していません。

予約制施設はエリア・工場見学一覧と詳細に掲載します。日付検索、今日・週末の一覧、常時無料一覧、自動SNS候補には含めません。無料範囲、予約条件、アクセス、有料体験等の注意点は `visit_info` に保存します。未確認施設を予約フラグだけで無料一覧に加えません。

新規URLは `/free/factory-tour/`、`/saitama/free/` と3施設詳細。canonical、サイトマップ、パンくず、関連リンクも生成します。

## 次の調査順

1. 千葉・埼玉・神奈川の食品工場、企業の体験施設を厚くする。
2. 群馬・茨城の候補を厚くし、その後愛知・兵庫へ広げる。企業ミュージアム、防災・環境学習施設も調べる。
3. 1回3〜5施設を目安に、予約不要・事前予約・抽選、子ども限定・一般、無料部分・有料部分を公式確認する。薄い一覧は量産しない。

次候補は未掲載・無料未確定です。優先度は情報の確かさ、アクセス、エリア内の選択肢、検索・SNSの実測で調整します。工場見学の流行や検索量の増加は今回確認していないため断定しません。

## 第2弾（2026-10-21）

さらに4施設を追加し、実装合計68施設・7都府県・9カテゴリになります。本番未反映。群馬県と茨城県、「展望施設」カテゴリを追加します。

- 群馬：ガトーフェスタ ハラダ本社工場見学ギャラリー。個人19名以下は予約不要、20名以上またはバス来館は要予約。日曜・元日休館。製造ラインの稼働は保証しません。2026/11/14は短縮営業：https://www.gateaufesta-harada.com/tour/headoffice 。
- 群馬：群馬県庁32階展望ホール。展望ホールの入場無料、飲食は別。県庁の一般開放休止に注意。時間は県の最新案内、無料料金は県公式観光案内で確認：https://www.pref.gunma.jp/page/1023.html 、https://www.visit-gunma.jp/en/spots/gunma-prefectural-office-observation-deck/ 。
- 茨城：めんたいパーク大洗。入場・工場見学無料、飲食・物販は有料。日祝は製造が稼働しない場合あり：https://mentai-park.com/ooarai/ 。
- 茨城：明治なるほどファクトリー守谷。無料・要予約。4歳未満は敷地にも入場不可、中学生以下は保護者同伴。個人は1か月前から予約：https://www.meiji.co.jp/learned/factory/moriya/visit.html 。住所の補助資料：https://www.maff.go.jp/kanto/syo_an/seikatsu/shokuiku/taiken/attach/pdf/syokunou_taiken_ibaraki-22.pdf 。

予約不要の見学と予約必須の見学を同じ扱いにしません。ハラダは日曜・元日を日付検索から除外し、明治は予約空き枠未確認のため日付検索と自動SNS候補へ出しません。展望施設はまだ1件のため、独立したSEO一覧は作らずカテゴリ検索で探せます。

こんにゃくパークは営業変更・改装等の最新案内の確認を継続中で、今回は追加しません。
