# SNSで集客する4週間の試験

Xは月・水・金17時、Instagramは火曜の画像投稿・木曜のリールを予定します。初回の下書きは2026年10月12日〜11月6日の20件です。日程は提案で、まだ投稿・予約投稿はしていません。

## 投稿素材を作る

`npm run social:pack -- --start 2026-10-12` で投稿文、動画入力JSON、確認用HTML、計測表CSVを `social/outbox/trial/` に生成します。確認済みの大人対象無料ルールと休館情報を利用し、同じ施設・日付や14日以内の連投を避けます。既存の実投稿履歴を参照しますが、下書きを投稿済みとして保存しません。候補がない日は省略し、manifestのskippedへ理由を残します。

投稿文の日付は無料になる対象日で、投稿予定日とは別です。各投稿前に施設公式サイトで臨時休館・予約・無料範囲を再確認してください。Instagramのプロフィールリンクは投稿先の施設ページか対応する一覧に更新し、ストーリーズは投稿キットのstory用リンクを使います。画像・リール内の文字URLはクリック導線になりません。

## golli-video-engineとの連携

入力JSONは `type: free_outing`。現在のgolli-video-engineの求人／サロン入力とは異なります。付属の `scripts/social/render.py` が変換・描画し、同エンジンの日本語文字描画とFFmpeg出力を再利用します。エンジン側のコードは変更しません。

既存エンジンの依存関係（Pillow・imageio-ffmpeg）を導入したPythonから実行してください。

```text
python scripts/social/render.py social/outbox/trial/投稿ID.video.json --engine /絶対パス/golli-video-engine --out social/outbox/trial/投稿ID
```

生成物：1080×1350の画像4枚、1080×1920のストーリーズ画像、1080×1920・30fps・15秒の無音リール。`--images-only` なら動画出力を省略します。実在施設の写真・音源は使わず、文字と図形だけで作成します。BGMは必要なら投稿時に使用権のある音源を選んでください。

## 計測

リンクは `utm_source=x|instagram`、`utm_medium=social`、`utm_campaign=free_day_trial`、`utm_content=施設ID_投稿予定日_x|carousel|story|reel` を付けます。既存日次X候補の `free_spot_daily` も維持します。リンク既定先をCloudflareの本番URLに変更しました。

GA4は同意した利用者のみ計測し、ページURLから検索入力・クエリ・参照元を除きます。こちらの生成形式に一致するSNSキャンペーン情報だけを明示的に設定します。設定前の投稿流入は今回の変更で過去にさかのぼって復元できません。

GA4の「セッションの参照元／メディア」「セッションのキャンペーン」「セッションの手動広告コンテンツ」で流入を比較します。`official_link_click`、`detail_link_click`、`search_submit` などを併せて確認します。未同意・計測ブロックされた訪問はGA4に含まれません。

CSVには予定情報だけを記入し、表示回数・サイト訪問・公式リンククリック・制作時間・収益は空欄です。公開後に実測値を記入してください。広告収入と紹介・スポンサー収入は契約・導入後の実収益を入力します。

## 4週間後の判断

フォロワー数より、投稿当たりのサイト訪問・公式リンク利用・制作時間当たりの訪問を比較します。画像と動画を同じ地域・施設の条件で比較して、続ける形式を決めます。現在の候補は東京・神奈川・大阪を含むため地域別にも分けて評価します。広告枠・スポンサー企画は流入と運営負担を確認してから具体化します。

既存のX自動投稿は今回有効化していません。Instagram連携、予約投稿、広告出稿、スポンサーへの連絡もしていません。
