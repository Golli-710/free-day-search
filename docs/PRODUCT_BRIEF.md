# 無料デー検索の判断基準

2026-10-21、ユーザー承認済み。

## 誰の課題を解決するか

首都圏で、週末のお出かけ先に迷う人。ひとり、友人、カップル、子ども連れを含む。子育て世帯だけに限定しない。

「近くて、予算に合って、行きたい日に開いている場所を見つけ、行き先を決めたい」を主課題とする。無料のお出かけ候補を入口に、実際の行き先選びを助ける。

## 掲載判断の必須3点

1. 行きやすさ：エリア・所在地・最寄駅・駅からのアクセス。車向け施設は駐車場条件も調べる。出発地からの所要時間や距離を推測しない。
2. 料金：通常料金と無料になる部分・対象者・対象日。有料体験、飲食、物販、駐車料金を分ける。未確認を0円としない。
3. 開いているか：通常営業時間、休館日、祝日の扱い、臨時変更。予約必須・抽選制は開催日と予約成立を分け、空き枠未確認なら参加できると断定しない。

公式URLと情報確認日を必ず保存する。文章が入力されていることと、公式情報で正確さを検証したことは分けて記録する。

## 優先順位

最優先は東京・神奈川・千葉・埼玉の選択肢を厚くすること。群馬・茨城は首都圏からの日帰り候補として扱い、行きやすさを個別確認する。大阪等の既存掲載は維持するが、愛知・兵庫への新規拡大はこの土台が整った後に再判断する。

工場見学というカテゴリ自体や施設数の多さだけで掲載順を決めない。同じ生活圏で比較でき、必須3点の根拠が揃う候補を優先する。カテゴリ、子どもの年齢、屋内外、興味等は追加の絞り込み条件。親子向け・雨の日向けは公式根拠なく推定しない。

## 直近の開発順

1. 既存施設のアクセス・料金範囲・開館条件の不足を棚卸しする。
2. 不足の補完と並行して、首都圏内の確認できた施設を追加する。
3. 一覧と詳細で必須3点を比較しやすくする。交通案内や予約確認へのリンクを整える。
4. 比較から施設詳細・公式確認への移動、再訪を実測する。PV・広告収益は成果指標として継続報告する。

SNS・SEO・広告の見せ方は、この情報基盤の上で工夫する。対象外の人を排除することや、未実装の移動時間・空席検索を約束することはしない。
